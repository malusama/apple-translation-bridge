启动接口服务

需要搭载 Apple Silicon 的 Mac，以及 macOS 26.4 或更新版本。首次使用请点击“下载语言包”，在系统窗口中准备英文和简体中文。下载完成后可离线运行。

  1. 确认语言包状态显示“已就绪”。
  2. 点击“启动接口服务”，等待状态变为“运行中”。
  3. 点击“复制接口地址”。默认地址为 http://127.0.0.1:3210/imme，如端口被占用，可在启动前修改。

配置沉浸式翻译

  1. 打开浏览器扩展的“设置 → 开发者设置”，启用 Beta 特性。
  2. 在“翻译服务”中选择“自定义接口”，填入 App 显示的接口地址。无需 API Key。
  3. 测试服务，将翻译服务设为“自定义接口”、目标语言设为简体中文，再翻译英文网页。

沉浸式翻译官方配置说明

接口仅接受本机连接。关闭窗口后服务继续运行；通过“窗口 → 打开翻译窗口”、⌘0、菜单栏图标或 Dock 重新打开窗口。点击“停止服务”或退出 App 会停止接口。登录时打开可在 App 中自行开启，默认关闭。

常见问题

提示语言包未安装：完成系统下载后点击“重新检查语言包”。首版提供英文和简体中文语言包的下载入口。

接口启动失败：检查端口是否已被其他服务占用，修改为另一个 1024 至 65535 的端口。

看不到自定义接口：先在沉浸式翻译的开发者设置中启用 Beta 特性。

浏览器扩展无法连接：确认 App 显示“运行中”，接口地址和端口一致；如浏览器询问本地网络访问权限，请根据自己的设置选择。

Support in English

This sandboxed Mac utility provides a local translation API using Apple's on-device Translation framework. It requires an Apple Silicon Mac with macOS 26.4 or later. Prepare English and Simplified Chinese language packs, start the API service, and copy its /imme address.

In Immersive Translate, enable Beta features in developer settings, select the custom API service, enter the copied address, and test it. No API key is required. Set the target language to Simplified Chinese. The server listens only on 127.0.0.1 and continues when the main window is closed. Use the Window menu or Command-0 to reopen the window. Quitting the app stops the service. The app's interface is in Simplified Chinese.

For assistance, open a GitHub issue. Include your macOS version and the error message. Please avoid posting private text that you translated.
