开始使用

需要搭载 Apple Silicon 的 Mac，以及 macOS 26.4 或更新版本。首次使用请点击“下载语言包”，在系统窗口中下载英文和简体中文。下载完成后可离线翻译。

  1. 在“英文”输入框中粘贴文本。
  2. 点击“翻译成中文”，或按 ⌘ Return。
  3. 在右侧查看、选择或复制译文。

接入沉浸式翻译

  1. 点击“启动接口”。默认端口为 3210，如被占用可修改端口。
  2. 复制接口地址，例如 http://127.0.0.1:3210/imme。
  3. 在沉浸式翻译的设置中选择“翻译服务 → 自定义接口”，填入地址，保存并测试。

接口仅接受本机连接。关闭窗口后 App 会留在菜单栏；从菜单栏退出 App 后，接口会停止。登录启动可在 App 中自行开启。

常见问题

提示语言包未安装：完成系统下载后点击“重新检查”。首版只提供英文到简体中文的下载入口。

接口启动失败：检查同一端口是否已有其他服务，修改为另一个 1024 至 65535 的端口。

浏览器扩展无法连接：确认 App 的接口显示“运行中”，地址端口一致；如浏览器询问是否允许访问本地网络，请根据自己的设置选择。

Support in English

This native Mac app translates English into Simplified Chinese using Apple's on-device Translation framework. It requires an Apple Silicon Mac with macOS 26.4 or later. Download the English and Simplified Chinese language packs in the app before translating offline.

To connect a compatible browser extension, start the local API and copy its /imme URL into the extension's custom translation service settings. The server listens only on 127.0.0.1. Quitting the app stops the server. The initial interface is in Simplified Chinese.

For assistance, open a GitHub issue. Include your macOS version and the error message. Please avoid posting private text that you translated.
