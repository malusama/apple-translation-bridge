翻译内容

本地翻译桥使用 macOS 的 Apple Translation 框架在本机处理文本。应用不会把原文或译文发送到我们的服务器，不提供账号，不保存翻译历史，也不包含广告、跟踪器或第三方分析 SDK。原文和译文在应用运行期间保留于内存，复制译文时会写入系统剪贴板。

本地设置和接口

应用仅在自己的沙盒内保存接口端口及接口启用状态。登录启动状态由 macOS 管理。接口只监听本机地址 127.0.0.1，不会开放到局域网。应用显示的请求数量和处理耗时仅保留在内存中。

Apple 系统服务

首次使用需要通过 Apple 系统服务下载语言包。Apple 可能按其自身政策收集 Translation API 使用情况；Apple 文档说明这些 API 使用指标不包含原文或译文。有关系统服务的信息，请参阅 Apple 隐私政策及 TranslationSession 文档。

外部链接与支持

主动打开帮助、源代码或提交问题会访问 GitHub；这些网站适用其各自的隐私政策。公开问题中的内容会被其他人看到，请勿附上私人翻译内容。隐私问题可通过 GitHub Issues联系项目维护者。

English

Local Translate Bridge processes source and translated text on your Mac through Apple's Translation framework. We do not operate a translation server, send text to our servers, save translation history, require accounts, or include ads, trackers, or third-party analytics SDKs. Text remains in memory while the app runs. Copying text writes it to the system clipboard.

The app stores its API port and enabled preference inside its own sandbox. macOS manages login startup. The optional local API binds only to 127.0.0.1. Request counts and timing are kept in memory.

Apple provides language-pack downloads and may collect Translation API usage metrics under its own policies. Apple's documentation states that these metrics do not include the source or translated text. External GitHub links and issue submissions are subject to GitHub's policies. For privacy questions, contact the maintainer through the repository's issues page.
